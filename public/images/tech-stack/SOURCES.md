# Tech Stack logo sources

- [Devicon](https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons) supplies the React, Next.js, Vue.js, TypeScript, JavaScript, Laravel, Ant Design, Tailwind CSS, Sass, Bootstrap, Material UI, PostgreSQL, Git, Visual Studio Code, Postman, Figma, and Vercel logos.
- [Go](https://go.dev/images/go-logo-blue.svg) supplies the blue Go wordmark.
- [CSS-Next](https://github.com/CSS-Next/logo.css/blob/bacc20878227204b283c68a6b935f8279e06b0cd/css.svg) supplies the CSS logo.
- [CoreUI](https://github.com/coreui/coreui/blob/main/docs/public/assets/brand/coreui-signet.svg) supplies the CoreUI signet.
- [TanStack Query](https://github.com/TanStack/query/blob/main/examples/react/prefetching-nextjs-app-router/app/icon.svg) supplies the Query emblem.
- [Simple Icons](https://github.com/simple-icons/simple-icons/blob/801eaab5b70f4933137069397ebbd2ce5f9ad56e/icons/drizzle.svg) supplies the Drizzle logo, displayed in its brand color.
- [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/codex-color.svg) supplies the color Codex logo.
